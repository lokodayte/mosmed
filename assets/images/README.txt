MOSMED — Images folder
======================

Drop your image files here. Reference them in the HTML like this:

  <img src="assets/images/your-file.jpg" alt="description" />

Suggested files to add:
  - founder.jpg       Portrait photo of the founder (3:4 ratio, min 600×800px)
  - hero-bg.jpg       Optional full-bleed hero background (min 1920×1080px)
  - logo.png          MOSMED logo (already referenced as assets/logo.png — 
                      you can also place a copy here if preferred)

Current path from the website root:  assets/images/filename.jpg
